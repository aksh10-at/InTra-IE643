# IE 643 Course Project — Official Problem Statement

> As allotted by the instructor/TAs. Saved verbatim for reference against the team's implementation plan.

## Allotted Project
Creating PDFs from handwritten lecture slide notes / handwritten scanned notes.

## Project Description
Given handwritten lecture notes from lecture slide notes (scanned handwritten pages), develop an AI-based document processing pipeline that recognizes handwritten text, equations, diagrams and structural elements and converts them into a clean, well-formatted digital PDF. The system should preserve the original content and logical structure while improving readability and organizing the notes into editable, searchable and professionally formatted documents.

## Expected Deliverables

1. **Handwritten Note Preprocessing:** Develop a preprocessing method for scanned handwritten notes, including image enhancement, noise removal, skew correction, page segmentation and layout analysis.
2. **Handwritten Content Recognition:** Develop/fine-tune a vision language model to recognize handwritten text, mathematical equations, symbols, tables and other lecture-note elements.
3. **Structure and Layout Understanding:** Develop/finetune a model to identify headings, subheadings, paragraphs, bullet points, equations, diagrams and page structure to preserve the organization of the original handwritten notes.
4. **Digital Note Reconstruction:** Develop/finetune a model to convert the recognized content into clean, readable and properly formatted digital pages while preserving the original meaning, equations, diagrams and overall logical flow.
5. **PDF Generation and Quality Evaluation:** Generate searchable, structured PDFs and evaluate recognition and reconstruction quality.

An extensive stage-wise report containing the reasons for the steps followed during the project, details about major experiments, datasets used, steps for dataset extraction, etc. The report should also cover the methodology for preparing the interface (if developed).
