# C++ Tutorials (16)

**6) Increment/Decrement Operator ⇒** Increment operator `(``++`)` is used to increase the value of the operand by 1, whereas the decrement operator `(``--`)` is used to decrease the value of operand by 1.

Ex ⇒
```
x++;   // Same as x = x+1
x--;   // Same as x = x-1
```

**7) Bitwise Operators ⇒** The Bitwise operators are used to perform bit level operations on the operands. The operators are first converted to bit-level and then the calculation is performed on the operands. Some Bitwise operators are:

1) & // Bitwise AND operator
2) | // Bitwise OR operator
3) ^ // Bitwise XOR operator
4) ~ // Bitwise Ones Complement operator
