## What do you mean by Type Casting / Type Conversion in C++?

A Type Casting or Type Conversion basically a conversion from one primitive data type to another primitive data type.

There are two types of type casting:

1. **Implicit Type Casting** (Automatic Type Casting)
   - In implicit or automatic casting, the compiler will automatically change one type of data into another.
   - Example sequence: `char → short int → int → unsigned int → long int → float → double → long double etc.`

2. **Explicit Type Casting** (Manual Type Casting)
