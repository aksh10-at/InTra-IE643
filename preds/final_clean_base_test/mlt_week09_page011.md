## Link Function

- **$g(z) = 0$ if $z=0$ (Point lying on the separator)**
- **$g(z) \rightarrow +1$ if $z \rightarrow \infty$**
- **$g(z) \rightarrow -1$ if $z \rightarrow -\infty$**

[Diagram: Sigmoid/Logistic Function]

The sigmoid/logistic function is defined as:

$$
g(z) = \frac{1}{1 + e^{-z}}
$$
