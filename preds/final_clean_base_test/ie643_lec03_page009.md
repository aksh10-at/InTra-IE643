# Hypoplane

A set of points \( x \in \mathbb{R}^d \) for which there exist:

- A non-zero vector \( w \in \mathbb{R}^d \)
- A scalar \( b \in \mathbb{R} \)

such that the equation \( <w, x> = b \) holds.

## Halfspaces

Two halfspaces associated with the equation \( <w, x> - b = 0 \):

1. \( <w, x> - b \geqslant 0 \)
2. \( <w, x> - b < 0 \)
