## Linear Separability Assumption

- No weight update after a finite number of mistakes made by the perceptron.

## Proof Outline

1. To run for a very large number of rounds ($T = \infty$).
2. The perceptron makes $M$ mistakes in these $T$ rounds.
3. To show: $M < \infty$
4. $M \leq B$
