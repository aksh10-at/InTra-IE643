# C++ Tutorials

## C++ Classes and Objects

### Definition of Class
- A class in C++ is the building blocks that lead to object-oriented programming.

### Explanation
- **Class**: A user-defined data type which holds its own data members and member functions, which can be accessed and used by creating an instance of that class.
- **Syntax**:
  ```cpp
  // User-defined Name
  Keyword - Class ClassName
  {
      Access Specifier: // Can be private, public or protected
      Data Members: // Variables to be used
      Member functions() // methods to access data members
      {
          Body of function;
      }
  };
  ```

### Key Points
- A class is like a blueprint for an object.
- A class is a user-defined data type which has data members and member functions.
