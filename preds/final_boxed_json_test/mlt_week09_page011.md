**Link Function**

$$g(z) = 0 \quad \text{if } z=0 \quad \text{(point lying on the separator)}$$
$$g(z) \rightarrow +1 \quad \text{if } z \rightarrow \infty$$
$$g(z) \rightarrow -1 \quad \text{if } z \rightarrow -\infty$$

$$g(z) = \frac{1}{1+e^{-z}} \quad \text{Sigmoid/logistic function}$$
