# C++ Tutorials

## Increment/Decrement Operator
The increment operator `++` is used to increase the value of the operand by 1. The decrement operator `--` is used to decrease the value of the operand by 1.

- Example:
  ```cpp
  x++; // Same as x = x + 1
  x--; // Same as x = x - 1
  ```

## Bitwise Operators
Bitwise operators are used to perform bit-level operations on the operands. The operators are first converted to bit-level and then the calculation is performed on the operands.

### Bitwise AND Operator (`&`)
- Example:
  ```cpp
  a & b;
  ```

### Bitwise OR Operator (`|`)
- Example:
  ```cpp
  a | b;
  ```

### Bitwise XOR Operator (`^`)
- Example:
  ```cpp
  a ^ b;
  ```

### Bitwise Ones Complement Operator (`~`)
- Example:
  ```cpp
  ~a;
  ```
