# Directional Derivative

For a function \( f : \mathbb{R}^d \to \mathbb{R} \), the directional derivative along some non-zero direction \( u \in \mathbb{R}^d \) at a point \( x \) is defined as:

$$
f'(x; \vec{u}) = \lim_{\alpha \downarrow 0} \frac{f(x + \alpha \vec{u}) - f(x)}{\alpha}
$$
