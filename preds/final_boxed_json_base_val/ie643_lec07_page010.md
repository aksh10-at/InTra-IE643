# Gradient Descent to Solve Minimization Problem

## Objective
Minimize \( f(x) \)
\[ f: \mathbb{R}^n \rightarrow \mathbb{R} \]

## Initial Setup
- Start at \( x^0 \in \mathbb{R}^d \)

## Iterative Process
For \( k = 0, 1, 2, \ldots \):

1. **Find a descent direction**
   - Determine the negative gradient direction.

2. **Find step length \( \alpha_k \)**

3. **Update the point**
   \[ x^{k+1} \leftarrow x^k + \alpha_k u^k \]
