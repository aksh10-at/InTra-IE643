## Hyperplane:

A set of points $x \in \mathbb{R}^d$ for which there exist a **non-zero** $w \in \mathbb{R}^d$ and a scalar $b \in \mathbb{R}$ s.t. $\langle w, x \rangle = b$ holds.

## Halfspaces

$$\langle w, x \rangle - b \geq 0$$
$$\langle w, x \rangle - b < 0$$

two halfspaces associated with $\langle w, x \rangle - b = 0$.
