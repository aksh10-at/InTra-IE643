# Gradient Descent to Solve Minimization Problem

## Objective
Minimize the function \( f(x) \) where \( x \in \mathbb{R}^n \).

### Algorithm Steps
1. **Start at** \( x^0 \in \mathbb{R}^d \).
2. **For** \( k = 0, 1, 2, \ldots \):
   - Find a descent direction \( u^K \).
   - Find step length \( \alpha_K \).
   - Update the point: \( x^{k+1} \leftarrow x^k + \alpha_K u^K \).

## Key Concepts
- **Local Minimum**
- **Saddle Points**
