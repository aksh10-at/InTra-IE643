# Split Inequalities

## Definitions and Theorems

- **If** $\beta^* \leq \beta$
  - Then it is valid for $S$ ($\alpha x \leq \beta$)
    - To check the inequality is valid for $S$, find:
      - $\beta^* = \max_{x \in S} \alpha x$

## Example

Let $S = S_1 \cup S_2$

[Diagram: Two overlapping regions labeled $S_1$ and $S_2$.]

Suppose $\alpha x \leq \beta$ is valid for both $S_1$ and $S_2$.

Then $\alpha x \leq \beta$ is valid for $S$.

## Finding Cutting Planes

- How to find cutting planes?
  - Split in different ways.
    - And inequality valid for both halves.
