## Diagram: Gradient Descent Visualization

The right side of the image illustrates an iterative procedure to find a local minimum point using gradient descent:

1. Start at a random point (e.g., $w_0$).
2. Move in the direction of the negative gradient ($-\nabla w_i$) to minimize the error function.
3. Repeat the process iteratively until convergence to a local minimum.

This diagram visually demonstrates how the algorithm progresses from an initial point towards a local minimum by following the negative gradient.
