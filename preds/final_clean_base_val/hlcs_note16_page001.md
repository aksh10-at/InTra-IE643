# C++ Tutorials

## Increment/Decrement Operator
- **Increment Operator (++)**: Used to increase the value of the operand by 1.
  - Example:
    ```cpp
    x++; // Same as x = x + 1
    ```

- **Decrement Operator (--)**: Used to decrease the value of the operand by 1.
  - Example:
    ```cpp
    x--; // Same as x = x - 1
    ```

## Bitwise Operators
- **Bitwise Operators**: Used to perform bit-level operations on operands. The operators are first converted to bit-level and then the calculation is performed on the operands.

### Bitwise Operators
1. **&** // Bitwise AND Operator
2. **|** // Bitwise OR Operator
3. **^** // Bitwise XOR Operator
4. **~** // Bitwise Ones Complement Operator
