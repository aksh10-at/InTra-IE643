# Recap: Supervised Learning with Perceptron

## Data Representation
\[
D = \left\{ (x^i, y^i) \right\}_{i=1}^{N < \infty}, \quad x^i = \begin{bmatrix}
x_{1}^{i} \\
x_{2}^{i} \\
\vdots \\
x_{d}^{i}
\end{bmatrix} \in \mathbb{R}^d := X
\]

## Binary Categorization/Classification
\[
y^i \in \{+1, -1\} := Y
\]

## Parametrized Function
$h: X \rightarrow Y$
