## Link Function

- $g(z) = 0 \quad \text{if} \quad z = 0$ (Point lying on the separator)
- $g(z) \rightarrow +1 \quad \text{if} \quad z \rightarrow \infty$
- $g(z) \rightarrow -1 \quad \text{if} \quad z \rightarrow -\infty$

## Sigmoid/Logistic Function

$$
g(z) = \frac{1}{1 + e^{-z}}
