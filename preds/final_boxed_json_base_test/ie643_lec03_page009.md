# Hypoplane:

A set of points \( x \in \mathbb{R}^d \) for which there exist a non-zero \( w \in \mathbb{R}^d \) and a scalar \( b \in \mathbb{R} \) such that \( <w, x> = b \) holds.

## Halfspaces

\[
<\omega, x> - b \geq 0
\]

\[
<\omega, x> - b < 0
\]

Two halfspaces associated with

\[
<\omega, x> - b = 0
\]
