Link Function

- $g(z) = 0 \text{ if } z=0$ (point lying on the separator)
- $g(z) \to +1 \text{ if } z \to \infty$
- $g(z) \to -1 \text{ if } z \to -\infty$

$$g(z) = \frac{1}{1+e^{-z}} \quad \text{(Sigmoid/logistic function)}$$
