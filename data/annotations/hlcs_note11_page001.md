# C++ Tutorials (11)

**4) Strings ⇒**
- String in C++ are used to store letters and digits.
- String can be referred to as an array of characters as well as individual data type.

Ex ⇒
```
char name[30] = "Hello";
or
String name = "Hello";
```

**5) Operators ⇒** C++ operator is a symbol that is used to perform mathematical or logical manipulations.

Types of Operators:
i) Arithmetic Operators
ii) Relational operators
iii) Logical operators
iv) Increment and Decrement operators (++ --)
v) Bitwise Operators (& |)
vi) Assignment operators (=)
vii) Conditional operators (?)
