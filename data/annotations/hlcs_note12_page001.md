# C++ Tutorials (12)

**Q ⇒** What do you mean by data types in C++?

**Ans ⇒** Data types define the type of data a variable can hold.
There are three types of data types in C++.

[Diagram: Box "Data types in C++" branching into three columns:]
- **Built-in type or Primitive type** → integer, character, Boolean, floating point, Double, Void
- **Derived data type** → function, Array, pointer, reference
- **User defined data type** → Class, Structure, Union, Enum, Typedef

**NOTE ⇒** Use `sizeof()` function to find all primitive data type size.

Ex ⇒ `sizeof(char)` ⇒ 1 (in byte)
