**3) Inheritance ⇒** When one class access the property (data member and member function) of another class is called Inheritance.

[Diagram: Box "Class A" (Superclass/Baseclass/parent class) with an arrow down to box "Class B" (Sub class/derived class/child class).]

Syntax ⇒
```
class A
{
  --- data member
  --- member fn
};

class B : public A
{
  ---
};
```
