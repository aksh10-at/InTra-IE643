# C++ Tutorials (14)

**2) Relational operators ⇒** These are used for the comparison of the values of two operands.

Ex ⇒ `==`, `>=`, `<=`, `>`, `<`

```
int a = 3;
int b = 5;
a < b;  // operator to check if a is smaller than b.
```

**3) Logical operators ⇒** Logical operators are used to combining two or more conditions/constraints or to complement the evaluation of the original condition in consideration.
The result of the operation of a logical operator is a Boolean value either True or false.
There are three logical operator.

1) `&&` // AND operator
2) `||` // OR operator
3) `!` // NOT operator

```
a>b && a>c
a>b || a>c
```
