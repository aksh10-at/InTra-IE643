## Mercer's Theorem

function $k: \mathbb{R}^d \times \mathbb{R}^d \rightarrow \mathbb{R}$ is a valid kernel iff

(1) $k$ is symmetric $[k(x,x') = k(x',x)]$

(2) For any dataset $\{x_1,\dots,x_n\}$ the matrix $K \in \mathbb{R}^{n\times n}$ where, $K_{ij}=k(x,x')$ is a positive semi definite matrix
