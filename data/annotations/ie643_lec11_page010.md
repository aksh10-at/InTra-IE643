## Conv. set

[Diagram: An oval region with two points $x_1, x_2$ inside connected by a line segment (both entirely within the oval) — a convex set. Beside it, a non-convex "M"-shaped/zigzag polygon where a connecting segment can exit the shape.]

set of pts. — $\mathbb{R}, \mathbb{R}^2, \mathbb{R}^d$ convex

Line seg connecting the two pts $x_1, x_2 \in C$ is defined as
$$\lambda x_1 + (1-\lambda) x_2 \quad \text{for } \lambda \in [0,1]$$
$\rightarrow$ convex combination of 2 pts

Line seg connecting 2 pts (chosen arbitrarily) chosen from $C$ should also belong to the same set $C$.
