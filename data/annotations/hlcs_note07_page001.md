# C++ Tutorials (07)

**Q ⇒** Explain Different features of C++.

[Diagram: A central oval "C++ features" with arrows out to boxes: Simple, Portable, mid-level, Structured, Rich Library, Object oriented, pointer, Compiler Based, faster, Memory management, Extensible.]

**1) Simple ⇒** It is a simple language in the sense that programs can be broken down into logical unit and parts, has a rich library support.

**2) Machine Independent or Portable ⇒** C programs can be executed in many machines with little bit or no change. But it is not platform-independent.

**3) Mid-level Programming Language ⇒** through C++ we can do both systems-programming and build large-scale user application so it is called mid-level programming.
