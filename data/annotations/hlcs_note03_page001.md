# C++ Tutorials (03)

**Q ⇒** What is C++ OOPs Concepts? Explain.

[Diagram: A central circle "Concepts of OOPs" with double-headed arrows connecting to seven boxes around it: Object, Class, Inheritance, Message Passing, Polymorphism, Abstraction, Encapsulation, Dynamic Binding.]

**1) Object ⇒**
- Any entity that has state and behavior is known as Object.
- Object is a "Active" Entity.
- An object is an instance of a Class.
- When a Class is defined, no memory is allocated but when it is instantiated (i.e. an object is created) memory is allocated.

**2) Class ⇒**
- Class is a Collection of Objects.
- Class is a "Passive" Entity.
- A Class is a user-defined data type which has data members and member functions.
